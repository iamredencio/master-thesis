01 / OBJECTIVE

What the model actually predicts

A probability that an NBA rookie will have a career spanning five or more calendar years, measured using the first and last NBA years in the archived career table. It does not predict salary, transfers, awards or an exact retirement date.

02 / VALIDATION

Forward-in-time separation

Fit on rookie cohorts from 1980–2004; choose regularization using 2005–2007; evaluate once on held-out 2008–2011. All model scaling statistics come from training only.

03 / MODEL

Regularized, interpretable baseline

A 13-feature L2 logistic regression using rookie per-game production, games played, efficiency, shooting and estimated rookie age. Stronger evidence is required before replacing it with a complex sequence model.

04 / DATA LIMITS

Historical does not mean current

Rookie records end in 2016. The career table ends in 2018, so only cohorts with sufficient observation time were labeled. The five-year target represents the first-to-last calendar span, not distinct seasons played.
